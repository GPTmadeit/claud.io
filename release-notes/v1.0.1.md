## Claud.io 1.0.1, the first Windows release

Claud.io is a desktop creative studio by **ANRCY**: design, video, audio-reactive visuals and 3D in one app.

### Downloads

| File | What it is | How to use it |
|---|---|---|
| `Claud.io-Setup-1.0.1.exe` | Installer (recommended) | Run it and follow the steps. Adds Start menu and desktop shortcuts, opens `.studio` files, updates itself. |
| `Claud.io-1.0.1-Portable.exe` | Portable app | Double-click to run, nothing is installed. Does not update itself. |
| `latest.yml`, `*.blockmap` | Update feed | Used by the installed app to update itself. You don't need to download these. |
| `SHA256SUMS.txt` | Checksums | Optional: compare with `Get-FileHash <file>` in PowerShell. |

**SmartScreen:** the exe is not code-signed yet. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

### What's in this release

- **Native Windows app** with installer, portable build, `.studio` file association and automatic updates from GitHub Releases.
- **New glass interface**: frosted, floating panels over a calm accent-tinted backdrop, a title bar that blends into the native window buttons, softer controls, menus and dialogs. Switch between Glass, Smooth and Grain under Appearance → Surface.
- **English by default** (German is still one click away on the flag button).
- **Works offline**: the libraries the studio loads on demand ship inside the app; fonts and other web resources are cached after first use.
- **About & updates**: click the logo for version info, credits and a manual update check. An "Update ready" button appears when a new version has downloaded.
- **Command palette** (`Ctrl+K`) now finds commands by their English names too.
- **AI assistant** uses the current Claude model.

### Updating

Installed copies check for updates at start and every few hours, download in the background, and install on restart.
